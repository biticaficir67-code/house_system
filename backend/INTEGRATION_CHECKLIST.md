# 表格第三步联调与验收清单

当前组内基线及本轮修正见 [TEAM_ALIGNMENT.md](TEAM_ALIGNMENT.md)。以下是后端接口的待执行清单，部分功能还没有页面入口；未勾选不表示已经验证。后端新增接口说明见 `WORKFLOW_IMPLEMENTATION.md`，基础字段见 `API.md`。

## 准备

- [ ] 使用隔离的 MySQL 8 开发库；当前基线为 house_system_latest.sql，不额外执行历史 V001～V003。已有数据先备份，不能直接覆盖；历史库另行核对升级路径。
- [ ] 核对 sys_admin 的管理员、broker 的本店与跨店经纪人，核对原表审核与启停字段；已有 latest 初始账号无需 bootstrap，账号清单见 TEAM_LOGIN.md。
- [ ] 前端使用 /api；正常业务用 Authorization: Bearer，申请阶段仅用 X-Application-Token。

## 注册与员工

- [ ] 注册后 PENDING，不能登录业务；申请凭证可查本人进度，不能读取房源。
- [ ] 密码错误、伪造或过期申请凭证不能查看拒绝原因与个人资料。
- [ ] 管理员拒绝，申请人查看原因、修改后重新提交，同账号无重复人员。
- [ ] 审核通过、原broker记录分配门店同时成功，不重复建立人员；重复点击审核只有一次生效。
- [ ] 普通员工更新不能绕过待审核/拒绝状态；经纪人不能改角色或门店。
- [ ] 本人改名/电话后原broker字段更新，管理员不填写电话；管理员停用后旧 token 无效，恢复后需重新登录。
- [ ] 最后一个可用管理员不能停用；不支持跨账号表转换身份；操作日志没有密码或 token。

## 房源、业主与客户

- [ ] 经纪人新增房源自动归本人，提交他人 ID 不会绕过权限；同店另一个人也看不到私有业务。
- [ ] 上传有效图片，设置封面与排序，移除封面后自动补选；文件类型、大小、数量超限明确提示。
- [ ] 媒体变更导致 version 更新、下架重审；批量上传结束后获取最新 version 再核验。
- [ ] 缺图片/户型/价格/有效负责人时无法上架；资料变更后旧核验不能直接复用。
- [ ] 有待执行预约时普通下架被提示阻止；自动下架保留预约，不会删除历史。
- [ ] 多业主独立普通委托可成立；共同独家委托用 jointWithId，规则不一致或另起冲突委托被拒绝。
- [ ] 重复手机号仅提示本权限范围，不强制合并，不泄露别人的档案。
- [ ] 新跟进保留旧记录，更新下一次联系计划；不填下次时间后旧待办消失。
- [ ] 匹配说明与实际预算/面积等一致；未填不限、无结果为空、无权与非在售房源不混入。
- [ ] 客户暂不跟进有原因，不计入活跃跟进待办；存在有效成交/预约时归档受限制。

## 预约与成交

- [ ] 预约、改期都检查同一经纪人30分钟冲突，重复/并发提交不多建记录。
- [ ] 只有待执行可改期/取消/完成，实际时间不在未来，取消记录不计实际带看。
- [ ] 管理员交接未完成预约前核对接收人时段及房源/客户归属；历史执行人不改写。
- [ ] 完成后进入首次待回访，回访后进入下一次联系计划，不覆盖原反馈。
- [ ] 登记成交只生成一笔有效记录，挂牌价不被成交价覆盖。
- [ ] 核实拒绝可见原因，更正后回到 PENDING；核实通过的记录不可普通编辑。
- [ ] 成交更新房源、客户、委托、预约；任一步失败整次撤回。
- [ ] 撤销后房源下架，客户依据其他有效成交调整，旧委托和取消预约不自动恢复。

## AI、统计和页面表现

- [ ] D 的两个真实服务可用时分别完成分析和估价；确认字段、单位、版本及请求快照。
- [ ] 关闭服务/超时/异常时房源仍保存，失败可见且可重试，不显示伪造价格或零价格。
- [ ] 反复打开详情不重复分析；特征改变标识旧结果过期；慢旧请求不覆盖新结果。
- [ ] 与 C 用同一组数据核对明细、工作台、汇总、导出，日期结束包含当天。
- [ ] 未核实/撤销成交、取消预约、LEGACY_DEMO 不混入真实口径。
- [ ] 无记录数量为零，无有效均价/比例分母为零返回空值。
- [ ] 经纪人不能通过报表参数或导出看到他人记录，导出无默认客户/业主电话。
- [ ] 页面按状态提供操作，提交期间防重复，保存失败保留输入，409 提示刷新，401 提示重新登录。

## 一条完整演示路线

经纪人申请 → 拒绝 → 重新申请 → 审核通过 → 房源录入与图片上传 → 核验上架 → 业主委托 → 客户需求匹配 → 预约 → 完成带看 → 回访 → 成交登记 → 管理员核实 → 报表核对 → 撤销成交 → 停用账号并核对历史。
