# 给成员 D：价格建议页怎么接进现有前端

这份说明只覆盖 **房价预测 / 价格建议报告**。  
房源文案智能分析（卖点标签、词云）是成员 B 的，端口 **5001**，目录 `ai_service/text_analyze/`，请不要改、不要合并进你的预测服务。

你的预测服务继续用自己的端口（选题里是 **5000**，`/ai/predict`）。Java 里 `ai/` 包会同时转文案和价格，两边接口分开。

---

## 1. 工作怎么划

| 谁 | 负责 | 不负责 |
| --- | --- | --- |
| B（本前端） | 房源列表每一行一个「价格建议」按钮；点了跳到约定路由 | 不写预测算法、不写报告页内容、不调 5000 |
| D | 价格预测 Python 前后端；**价格建议报告整页 Vue**；数据看板里「AI 辅助定价」四张效果图（有余力再做） | 不改房源录入、业主客户带看、文案分析块、登录审核 |
| A | Java `ai/` 转发 `/ai/predict`，必要时把单次预估写入 `house_price_pred` | 不训模型 |
| C | 库存/价格/带看等报表图 | 不画定价报告正文（除非和你商量代画看板第四栏） |

B 的房源页 **只提供入口**。报告页的页面文件、接口、图表都由你提交到自己的分支，再合进 `frontend`。

---

## 2. 跳转约定（请按这个接）

房源列表操作列：

```text
按钮文案：价格建议
跳转：/price-advice/:houseId
例如：/price-advice/12
```

浏览器地址里的 `houseId` 就是当前房源主键。  
需要更多字段时可以用 query（可选）：

```text
/price-advice/12?title=某某小区-三室
```

B 会写好路由占位。请你提供（或自行添加）对应的页面组件，例如：

```text
frontend/src/views/PriceAdvice.vue
```

在 `router/index.js` 里挂到 `/price-advice/:houseId`。  
在你的页面写好之前，该路由可以暂时是一句「价格建议报告由算法模块接入」。你接上之后换成自己的页面即可，**不要改按钮的跳转路径**，免得列表还要再改。

登录态：该页需要已登录。Token 与 B 其它页相同（A 的 auth）。你这边用 axios 时带上同样的 Token 头。

## 3. 页面主题色（必须跟这一套）

从项目色板取，不要另起一套蓝绿科技风。

| 用途 | 色值 |
| --- | --- |
| 主强调（按钮、当前导航、重要数字） | `#B57920` |
| 主强调深一档（悬停、选中） | `#C97D0B` |
| 高亮、图表主色 | `#F7B500` |
| 图表辅色、标签浅底 | `#F9D24C` |
| 浅底、弱背景条 | `#FAE493` |
| 边框、分割线、次要文字偏冷灰 | `#C6C6C7` |
| 导航条、次要图例、信息提示 | `#96A3BF` |

使用注意：

- 页面底用近白（可略带一点浅黄，不要大面积 `#B57920` 铺底，大屏会刺、字也看不清）。
- 正文用深色（接近黑），不要用浅黄写小字。
- 主按钮：底 `#B57920`，字白；悬停 `#C97D0B`。
- 图表：金黄系列为主，冷灰蓝 `#96A3BF` 作对比即可，不要彩虹色。
- 卡片白底、细线 `#C6C6C7`。悬停可轻微上浮；点图放大和 B 的数据看板一致更好。

登录和业务页是暖色住宅/室内风。报告页保持同一套按钮和标题字号，不要做成完全不同的后台皮肤。

## 4. 和「数据看板」第四栏的关系

| 位置 | 谁写 | 看什么 |
| --- | --- | --- |
| 房源列表 → 价格建议 | **D 整页** | **这一套房** 的估价、建议区间、和挂牌价对比 |
| 数据看板最下面「AI 辅助定价」 | D 插图（或 D 出数据 C 出图） | **全库** 成功率、偏差、参考层级、调用量 |

两处都不要和房源详情里的「文案智能分析」（标签/词云）混在一个框里。

看板第四栏的图槽 id 预定如下，你插入时用这些名字，B 会在看板页留空卡：

- `chart-ai-success` 预估成功率
- `chart-ai-bias` 预估与挂牌偏差
- `chart-ai-ref-level` 参考层级
- `chart-ai-calls` 调用量趋势

未接好时卡片上写「由价格预测模块接入」。

## 5. 建议你怎么接到 Java

后端包：`.../ai/`（文案与价格服务接入）。  
价格走 A 转发，前端尽量 **只打 Java**，不要在浏览器里直连 `localhost:5000`（跨域和部署都会麻烦）。

具体路径等 A 的接口文档。你需要给 A 的 Python 约定仍是选题里的：

```text
POST http://localhost:5000/ai/predict
```

报告页至少应能根据 `houseId` 向 Java 要：户型、面积、挂牌价、以及预测结果。缺字段时在页上提示，不要把 Java 打挂。

2. 点击后地址变为 `/price-advice/{id}`，出现的是 **你的报告页**，不是文案标签。  
3. 未登录会被拦回登录页。  
4. 文案智能分析仍在房源详情，颜色和按钮风格与报告页接近。

有路径或色值冲突，先在群里说，不要直接改 B 已经定的 `/price-advice/:houseId`。
