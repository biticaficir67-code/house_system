# 报表中心

组内数据看板 `/dashboard` 复用 NavMain、Vuex 登录状态和全局 Axios 拦截器。正式模式只请求业务报表接口，接口失败不会回退为示例数据。

`/reports/preview` 是公开的独立示例预览，只读取确定性的本地样本。预览隐藏业务导航，不能请求业务接口，不改变登录状态或正式看板权限。

## 文件

- `Dashboard.vue`：Vue 生命周期、Axios 和 Element Plus 消息适配。
- `reportEngine.mjs`：ECharts 实例、报表数据加载、筛选、视图保存和导出。
- `report-base.css`：报表基础控件与组内 CSS 变量衔接。
- `report-layout.css`：限定在 `.reports-host` 内的看板布局，按组内金色、灰蓝配色适配。

正式页面按路由延迟加载。离开页面时销毁图表、ResizeObserver 与专注模式；示例与正式模式的保存视图分开存储，不保存业务数据或令牌。

## 校验

```sh
npm install
npm run test:reports
npm run build
npm run dev -- --host 127.0.0.1 --port 5174
```

访问 `http://127.0.0.1:5174/reports/preview` 可预览。正式页面通过组内登录进入“数据看板”，业务接口由 Vite 代理到 8080。完整后端联调需可用数据库和已启用账号。

## 数据口径

房源以挂牌日期筛选；结构图仅统计在售。带看仅计完成的新业务，成交仅计有效且已核实记录。聚焦只联动同维度图表，顶部指标仍保持日期、门店的全局口径。热力图和雷达图按指标内最大值标准化，原始值保留于提示、明细和导出。

支持 12 种图形、12 个聚合数据集、日期与门店筛选、度量与排序切换、聚焦联动、图表放大、专注模式、CSV 与 PNG 导出、浏览器本地保存视图。
